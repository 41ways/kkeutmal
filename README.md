# 📝 끝말잇기

![종류](https://img.shields.io/badge/%EC%A2%85%EB%A5%98-%EB%A7%90%EB%86%80%EC%9D%B4-d0543a?style=flat-square) ![인원](https://img.shields.io/badge/%EC%9D%B8%EC%9B%90-1~8%EC%9D%B8-555?style=flat-square) [![플레이](https://img.shields.io/badge/%ED%94%8C%EB%A0%88%EC%9D%B4-kkeutmal.41ways.workers.dev-2b2622?style=flat-square)](https://kkeutmal.41ways.workers.dev/) [![허브](https://img.shields.io/badge/%ED%97%88%EB%B8%8C-norara-b4571f?style=flat-square)](https://41ways.github.io/norara/)

표준국어대사전 **21만 낱말**로 하는 온라인 끝말잇기. 끄투처럼 방을 만들어 여럿이, 혹은 봇과.
낱말이 받아들여지면 원고지 칸에 한 글자씩 박히고 뜻풀이가 뜬다.

## 한눈에

| | |
|---|---|
| **종류** | 말놀이 · 온라인 · 실시간 |
| **인원** | 1~8인 (봇으로 채우면 혼자도) |
| **플레이** | **https://kkeutmal.41ways.workers.dev/** |
| **로컬 실행** | `npm install && npm start` → http://localhost:8820 |
| **한 줄 규칙** | 앞 낱말의 끝 글자로 시작하는 명사를 제한 시간 안에 친다. 못 치면 −50점 |
| **허브** | https://41ways.github.io/norara/ |

**목차** — [규칙](#규칙) · [점수](#점수) · [모드와 방 설정](#모드와-방-설정) · [봇](#봇) · [화면](#화면) · [사전](#사전) · [실행](#실행) · [배포](#배포-cloudflare-workers-무료-플랜) · [시험](#시험) · [구조](#구조) · [저작권](#저작권)

## 규칙

- 앞 사람 낱말의 **끝 글자**로 시작하는 낱말을 치고 Enter.
- **두음 법칙**이 된다 — ‘력’으로 끝나면 ‘역’으로, ‘로’로 끝나면 ‘노’로 시작해도 된다.
  (ㄹ→ㄴ: ㅏㅐㅗㅚㅜㅡ, ㄹ→ㅇ: ㅑㅕㅖㅛㅠㅣ, ㄴ→ㅇ: ㅕㅛㅠㅣ — 끄투와 같은 범위)
- 사전에 있는 **명사**(대명사·수사 포함)만, 두 글자 이상, 한 판에서 한 번씩만.
- 한 판은 여러 **라운드**. 판이 시작될 때 라운드 수만큼 글자가 있는 **제시어**가 뽑히고(예: 5라운드면 ‘생물정보학’), 라운드마다 그 글자로 새로 시작한다.
- 차례마다 **차례 시간**이 있고, 라운드 전체에 **라운드 시간**이 흐른다. 둘 중 하나라도 다 가면 그 차례인 사람이 **−50점**, 라운드가 끝난다. 다음 라운드는 그 사람부터.
- 차례 시간은 처음 10초에서 한 번 이어질 때마다 0.3초씩 줄어 3.5초까지 (쿵쿵따는 7초 → 2.5초).
- 막히면 입력칸 옆 **포기**로 바로 넘길 수 있다. 시간 초과와 똑같이 −50, 라운드 끝이고 판에도 ‘시간 초과’ 도장이 찍힌다.
- 라운드 시간을 **없음**으로 하면 라운드 · 차례 시계가 모두 꺼진다. 막히면 포기로 넘기고, 봇도 막히면 잠깐 고민하다 포기한다. 차례인 사람이 연결이 끊기면 8초 뒤 넘어간다.
- 이을 말이 사전에 하나도 없는 낱말(**한방 단어**)을 받으면 5초만 기다리고 넘어간다. 한방을 내면 판에 ‘한방!’ 도장이 찍힌다.
- 입력칸은 하나다. **내 차례에 한글만 친 것은 낱말**, 그 밖에는 채팅.
  앞 사람 낱말이 받아들여지고 내 차례가 열리기 직전(0.45초)에 친 낱말은 채팅으로 새지 않고 내 차례에 들어간다.
- 시간이 다 가면 “이런 말이 있었음 → ○○” 으로 이을 수 있던 흔한 낱말 하나를 보여 준다.

## 점수

```
기본  = 4 + 4n + n²          (n = 글자 수 · 2글자 16 · 3글자 25 · 5글자 49 · 8글자 100)
이음  × (1 + 0.04 × 이어진 횟수)   (25번까지)
빠르기 × (0.7 + 0.6 × 남은 차례 시간 비율)      (시간제한 없음이면 1)
미션  × (1 + 0.5 × 미션 글자 개수)
```

긴 낱말을 빨리, 긴 줄 끝에서 칠수록 크다. 시간 초과는 −50.

## 모드와 방 설정

방장만 바꿀 수 있고, 대기실에서만 바뀐다.

| 설정 | 고를 수 있는 것 | 기본 |
|---|---|---|
| 모드 | **끝말잇기** · **쿵쿵따**(세 글자 낱말만, 차례가 짧다) | 끝말잇기 |
| 라운드 | 3 · 4 · 5 · 6 | 5 |
| 라운드 시간 | 60 · 90 · 120 · 150초 · **없음**(시계 없이, 막히면 포기) | 60초 |
| 봇 실력 | 쉬움 · 보통 · 어려움 | 보통 |
| 미션 글자 | 켜면 위에 글자 하나가 뜨고, 그 글자가 든 낱말은 점수 1.5배. 쓰면 새 글자로 바뀐다 | 끔 |
| 한방 금지 | 켜면 이을 말이 없는 낱말은 받지 않는다 | 끔 |
| 외래어 금지 | 켜면 ‘버스’, ‘컴퓨터’ 같은 외래어와 ‘버스표’처럼 외래어가 섞인 말은 받지 않는다. 봇도 안 쓴다 | 끔 |
| 비공개 | 방 목록에 안 뜨고 코드로만 들어온다 | 끔 (혼자 연습은 켬) |

- 첫 화면의 **열린 방** 목록은 실시간으로 바뀐다. 누르면 들어간다.
- **빠른 입장**은 사람이 기다리는 공개 방 가운데 가장 붐비는 곳으로, 없으면 새 방을 만든다.
- **혼자 연습**은 봇 셋과 비공개 방을 바로 만든다.
- 판 중인 방에도 들어올 수 있다. 구경하다가 다음 판부터 낀다.
- 방장은 판 중에 **판 접기**로 지금 점수 그대로 순위를 매기고 끝낼 수 있다.
- 판이 끝나면 결과 창이 뜬다. 방장은 **한 판 더**(Enter)로 같은 설정 그대로 바로 다시 시작하거나 **대기실로** 돌아가 설정을 바꾼다.
- 방 코드를 누르면 초대 링크(`…/#ABCD`)가 복사된다. 링크로 오면 이름만 적고 들어간다.

## 봇

| 실력 | 생각 시간 | 고르는 낱말 | 생각이 안 날 확률 |
|---|---|---|---|
| 쉬움 | 2.2~4.2초 + 글자당 0.18초 | 흔한 낱말, 세 글자 이하를 먼저 | 12% |
| 보통 | 1.3~2.6초 + 글자당 0.11초 | 흔한 낱말, 없으면 60% 확률로 전체 사전 | 4% |
| 어려움 | 0.6~1.4초 + 글자당 0.06초 | 전체 사전에서 **길고, 다음 사람이 잇기 어려운** 낱말 | 1% |

‘흔한 낱말’은 hunspell 맞춤법 사전의 명사 3.2만 개다. 어려움 봇은 ‘끈끈켜’, ‘업시름’ 같은 사전 깊숙한 말로 몰아붙인다.
생각 시간이 차례 시간보다 길면 그 봇도 시간 초과로 진다.

## 화면

- **원고지** — 받아들여진 낱말이 원고지 칸에 한 글자씩 도장처럼 박히고, 그 옆 점선 칸에 다음에 칠 글자(두음 법칙이면 ‘또는 역’)가 숨 쉰다.
- 뜻풀이는 소리가 같은 낱말을 넷까지 ①②③④로 보여 준다. 표준국어대사전의 번호는 쓰임 순서가 아니라서(사과01 이 ‘참외’) 분야 표시가 없는 일반 뜻을 앞에 세웠다.
- 위에는 제시어가 칸으로 뜨고 지금 라운드 글자가 칠해진다. 그 아래 라운드 · 차례 시간 막대, 차례가 3초 아래로 떨어지면 빨개진다.
- 이어 온 낱말은 판 아래 한 줄로 쌓인다(내 낱말은 파란 테).
- 내 차례가 되면 입력칸에 빨간 테와 ‘낱말’ 표가 붙고, 탭을 보고 있지 않으면 제목이 ‘▶ 내 차례!’로 깜빡인다.
- 틀린 낱말은 모두에게 “✗ 낱말 — 사전에 없는 말” 처럼 흔들려 보이고, 내 입력칸에는 친 말이 되돌아와 고쳐 칠 수 있다.
- 소리는 기본으로 꺼져 있다(오른쪽 위 🔈).
- 한글 입력기로 마지막 글자를 조합하던 중에 Enter 를 눌러도 글자가 빠지거나 빈칸에 남지 않게, 조합이 끝나기를 기다렸다가 보낸다.

## 사전

| | |
|---|---|
| 판정 낱말 | **213,334개** — 표준국어대사전의 명사·대명사·수사 가운데 한 낱말인 것(구·관용구·속담 제외), 방언·북한어·옛말·비표준어 뜻만 있는 것 제외 + hunspell-dict-ko 명사 |
| 흔한 낱말 | 32,426개 — hunspell-dict-ko 명사 (봇 · 제시어 · 힌트용) |
| 외래어 | 23,389개 — 사전의 낱말 갈래가 외래어이거나, 혼종어 가운데 한자·고유어가 아닌 원어(영어, ‘안 밝힘’ 음역 등)가 섞인 말. 소리가 같은 고유어·한자어가 하나라도 있으면 막지 않는다. hunspell 에만 있는 낱말은 사전에 다른 품사로 외래어가 있거나(럭스), 앞뒤가 외래어(킬로그램 · 팬미팅)이거나, 외래어에만 나오는 글자가 있으면 외래어로 친다 |
| 뜻풀이 | 211,383개 — 첫 글자별 1,440개 조각(`public/dict/<16진수>.json`, 20MB). 화면이 낱말을 띄울 때 그 조각만 받는다 |
| 쿵쿵따 | 세 글자 낱말 89,457개 |

만드는 법:

```bash
python3 tools/fetch-stdict.py /tmp/stdict     # 표준국어대사전 XML 87개(약 460MB)를 하나씩 받아 표제어만 뽑고 지운다
curl -O https://raw.githubusercontent.com/spellcheck-ko/hunspell-dict-ko/master/dict-ko-data.yaml
python3 tools/build-dict.py /tmp/stdict/stdict.tsv dict-ko-data.yaml
```

`dict/words.txt`(한 줄에 한 낱말, 흔한 낱말은 앞에 `*`, 외래어가 든 말은 `~`)는 서버가 판정에 쓰고, Worker 에 글자열로 묶여 들어간다(압축 0.8MB).

## 실행

```bash
npm install     # 최초 1회
npm start       # http://localhost:8820
```

같은 와이파이의 친구는 `http://<내 IP>:8820` 으로 들어온다.

## 배포 (Cloudflare Workers 무료 플랜)

`wrangler.toml` 에 설정이 다 들어 있다. 화면 파일과 뜻풀이 조각(`public/`)은 정적 자산으로, 소켓(`/ws`)만 Durable Object 하나로 간다. 방은 전부 그 안에 산다.

```bash
npx wrangler login     # 처음 한 번
npx wrangler deploy
```

- 사전은 Worker 가 켜질 때가 아니라 Durable Object 가 처음 깰 때 한 번 편다(38ms · 34MB).
- 무료 한도는 하루 단위라 넘어도 다음 날이면 다시 찬다. 결제 수단이 없으니 요금은 붙지 않는다.
- 켜진 시간을 아끼려고 **20분 동안 아무 조작이 없는 연결은 서버가 닫는다.** 화면을 다시 누르면 이어 붙는다.
- **GitHub 에 푸시하는 것만으로는 반영되지 않는다.** 고친 뒤 `npx wrangler deploy` 까지 해야 한다.

## 시험

```bash
npm test                                           # 판 로직 — 가상 시계로 봇 판을 난이도·모드별로 끝까지 돌린다
node test/smoke.js http://localhost:8820           # 떠 있는 서버
node test/smoke.js https://kkeutmal.41ways.workers.dev
```

`npm test` 는 두음 법칙, 판정 이유, 점수, 시간 초과와 감점, 라운드 넘김, 쿵쿵따 글자 수, 한방 금지, 외래어 금지, 시간제한 없음과 포기, 판 중에 나가기·들어오기, 빠른 입장, 새로고침까지 20가지를 본다.
봇 판에서는 모든 낱말이 앞 낱말에 이어지는지(두음 법칙 포함), 한 판에 같은 낱말이 두 번 나오지 않는지 확인한다.

## 구조

```
game.js              사전 · 두음 법칙 · 판정 · 차례와 라운드 · 점수 · 봇 · 방 목록. 통신 방식은 모른다
worker.js            Cloudflare Workers 서버 — 소켓을 Durable Object 하나로 받아 game.js 에 넘긴다 (실제 서비스)
server.js            Node 서버 — 같은 game.js 를 ws 로 띄운다 (로컬 개발 · 시험)
dict/words.txt       판정용 낱말 목록
public/dict/*.json   뜻풀이 조각
public/index.html · style.css · app.js   화면
tools/               사전 만드는 스크립트
test/game.js         판 로직 시험 (서버 없이)
test/smoke.js        떠 있는 서버 확인
```

서버가 판정을 쥐므로 화면을 조작해도 낱말이나 점수를 속일 수 없다.
